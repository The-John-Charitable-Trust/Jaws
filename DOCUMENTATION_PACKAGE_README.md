# JAWS documentation update — two installation guides

This is a **documentation-only overlay**. Extract into the root of an existing JAWS repository. It intentionally does not contain `installer/`, `src/`, or a replacement repository-root README.

Contents:
- `docs/installation/index.html` — choose standard or developer/tester guide
- `docs/installation/standard/index.html` — customer-facing setup, no Pester
- `docs/installation/developer/index.html` — testing, Pester 5, .NET, Stage A
- `docs/verification/index.html` — existing manual verification guide preserved
- `docs/installation/README_LINKS.md` — suggested links to append to repository README

**Caution:** The repository's root README must not be overwritten with this handoff README.
The current Stage A installer is discovery-only; standard Install mode is planned for Stage B.
