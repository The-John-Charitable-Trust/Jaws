# JAWS

JAWS is an agentic operations platform being rebuilt from a clean open-source foundation.

This repository intentionally starts with no application code. We will add code incrementally as we work through the Microsoft Agent Framework table of contents, beginning with Step 1: Your First Agent.

## Current Scope

- Clean public/open-source track
- No copied implementation code from prior private work
- No tenant-specific Azure, ServiceNow, Datadog, or Teams configuration
- Code will be added only as each Microsoft Agent Framework step is designed, approved, implemented, and tested

## Initial Milestone

Step 1 will establish the first minimal agent implementation, configuration model, deployment walkthrough, and test cases.
