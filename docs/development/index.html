Introduction

JAWS Platform Overview

JAWS is an agentic investigation and operational coordination platform. Its Microsoft Foundry-hosted Supervisor coordinates specialized agents, with tool access mediated through MCP servers, identity enforcement and human approval. Evidence, context and decisions must remain traceable. The architecture is modular; unfinished workers and integrations are not represented as deployed.

Operational Reference Architecture

Concept of Operations

An authorized operator initiates a request through Teams or an operational workbench. The Supervisor identifies the task, scopes it to the operator's permissions, and routes bounded investigations to specialist agents. Specialist agents retrieve evidence through controlled Azure and custom MCP tools. Independent review, source citations, auditable context and human approvals govern any potentially consequential operation.

Primary use case

Investigate an Azure operational incident: collect Policy, Defender and observability evidence; identify likely causes; compare remediation options; present cited findings and what-if impact; request explicit approval before any authorized execution; retain traceable evidence of actions and outcomes.

Agent communication and evidence contract

Every delegated task should carry correlation and session identity, least-privilege authorization, explicit scope and timeout, structured outputs and source citations. The Supervisor must not represent unconnected tools as available or claim remediation occurred without verifiable execution evidence.
