Stage B: Installer Foundation

B2 first checkpoint: offline Plan blueprint implemented, not yet acceptance-tested. The new -Mode Plan validates 16 deployment dependencies without connecting to Azure. It reports all proposed resources as RequiresAzureDiscovery, explicitly blocks execution and does not estimate actual costs. It does not deploy or authorize any resources.

Copy installer/config/jaws-stage-b-plan.example.json to a local file under installer/.local/, replace the example subscription ID with an authorized subscription, then execute:

New-Item -ItemType Directory -Force .\installer\.local | Out-Null
Copy-Item .\installer\config\jaws-stage-b-plan.example.json .\installer\.local\jaws-plan.tester.json
# Edit jaws-plan.tester.json with a real authorized subscription ID and target.
.\installer\Install-Jaws.ps1 -Mode Plan -PlanFile .\installer\.local\jaws-plan.tester.json
Import-Module Pester -RequiredVersion 5.9.1 -Force
Invoke-Pester .\tests\installer\ -Output Detailed

Expected: a BLOCKED_PENDING_AZURE_DISCOVERY_AND_APPROVAL offline report under installer/.local/; zero Azure calls/writes. No Install mode is available in this source branch yet. Future work must add real authorized state reconciliation, SKU/cost validation, approvals, and deployment before it becomes executable.

All Azure provisioning/configuration exclusively via JAWS installer. Never use tutorial directions for direct Azure resource changes.
