Step C: Investigation Agent and Supervisor Delegation

Code-first implementation tutorial. Phase 1: offline typed contracts, deterministic planning and delegation validation. No Azure writes or runtime redeployment.

1. Scope and learning outcomes

Step C's first implementation increment defines the task and result contracts for a dedicated Investigation Agent, builds a deterministic offline planning agent and a Supervisor-side delegation boundary, and tests fail-closed behaviors. It does not create a second Foundry hosted agent, modify the accepted Supervisor v1 or connect Azure/Datadog MCP.

2. Supervisor-to-Investigation control flow

User request → trusted ingress and authorization broker (future)
    ↓ verified typed InvestigationTask
SupervisorInvestigationDelegator (implemented offline)
    ↓ Validate task & broker marker
IInvestigationAgent.InvestigateAsync (in-process planner)
    ↓ InvestigationResult(Status=Planned, Evidence=[])
Supervisor validates task & correlation IDs, schema and success evidence
    ↓
Return plan with explicit "NO PROVIDER EVIDENCE" diagnostic

The source currently demonstrates the delegation contract using in-process calls. It does not establish trusted ingress, actual broker verification, remote service authentication or genuine Microsoft Foundry agent-to-agent transport. These remain mandatory gates before a live worker can access tools.

3. Define immutable, typed investigation contracts

The contracts carry task ID, correlation ID, identity binding, resource scope, permitted tool names, deadline, evidence references and diagnostics. The IsVerifiedByBroker flag is an offline test marker, not a production authentication mechanism.

C#Actual file: src/Jaws.Investigation/InvestigationContracts.cs
using System.Text.Json.Serialization;

namespace Jaws.Investigation;

/// <summary>Validated, broker-supplied scope. Never populate from untrusted model/user text.</summary>
public sealed record VerifiedInvestigationScope(
    string TenantId,
    string UserObjectId,
    string ProjectId,
    string ConversationId,
    string AuthorizationContextRef,
    string TargetResourceScope,
    IReadOnlyList<string> AllowedToolNames,
    DateTimeOffset DeadlineUtc,
    bool IsVerifiedByBroker);

public sealed record InvestigationTask(
    string SchemaVersion,
    string TaskId,
    string CorrelationId,
    string OriginatingTeamsMessageId,
    string RequestedOperation,
    VerifiedInvestigationScope Scope);

[JsonConverter(typeof(JsonStringEnumConverter))]
public enum InvestigationStatus { Planned, Partial, Denied, Failed, Succeeded }

public sealed record EvidenceReference(
    string Provider,
    Uri SourceUri,
    string ResourceScope,
    string ClaimId,
    DateTimeOffset ObservedAtUtc);

public sealed record InvestigationResult(
    string SchemaVersion,
    string TaskId,
    string CorrelationId,
    string AgentName,
    string AgentVersion,
    InvestigationStatus Status,
    IReadOnlyList<string> EvidenceRequirements,
    IReadOnlyList<EvidenceReference> Evidence,
    IReadOnlyList<string> VerifiedClaims,
    IReadOnlyList<string> ProposedActions,
    IReadOnlyList<string> Diagnostics);

public interface IInvestigationAgent
{
    Task<InvestigationResult> InvestigateAsync(
        InvestigationTask task,
        CancellationToken cancellationToken = default);
}

4. Write the Investigation planning agent

The first implementation returns an evidence-collection plan for an Azure VM compliance investigation. It refuses unknown operations, expired deadlines, unverified scope and non-allowlisted tools. Because no Azure MCP call occurs, verified claims and evidence remain empty.

C#Actual file: src/Jaws.Investigation/InvestigationPlanner.cs
namespace Jaws.Investigation;

/// <summary>
/// Offline deterministic investigation-planning stub.
/// No model calls, MCP access, Azure queries, or remediation execution.
/// Replace with a separately authenticated specialist only after authorization
/// and hosted-agent A2A transport have been implemented and accepted.
/// </summary>
public sealed class InvestigationPlanner : IInvestigationAgent
{
    private static readonly string[] Requirements =
    [
        "Resolve the exact target resource identity and authorized subscription scope.",
        "Obtain Azure Policy compliance state and matching policy assignment from an authorized provider.",
        "Obtain relevant Defender for Cloud recommendations from an authorized provider.",
        "Correlate observations with their timestamps, resource IDs and provider source URLs."
    ];

    public Task<InvestigationResult> InvestigateAsync(
        InvestigationTask task, CancellationToken cancellationToken = default)
    {
        ArgumentNullException.ThrowIfNull(task);
        cancellationToken.ThrowIfCancellationRequested();

        string? rejection = Validate(task);
        var status = rejection is null ? InvestigationStatus.Planned : InvestigationStatus.Denied;

        // No provider call has occurred, so Evidence and VerifiedClaims stay EMPTY.
        return Task.FromResult(new InvestigationResult(
            SchemaVersion: "1.0",
            TaskId: task.TaskId,
            CorrelationId: task.CorrelationId,
            AgentName: "jaws-investigation",
            AgentVersion: "offline-step-c-0",
            Status: status,
            EvidenceRequirements: rejection is null ? Requirements : Array.Empty<string>(),
            Evidence: Array.Empty<EvidenceReference>(),
            VerifiedClaims: Array.Empty<string>(),
            ProposedActions: Array.Empty<string>(),
            Diagnostics: rejection is null
                ? ["PLAN_ONLY: No Azure Policy/Defender/Datadog evidence has been retrieved."]
                : [rejection]));
    }

    public static string? Validate(InvestigationTask? task)
    {
        if (task is null || task.Scope is null)
            return "DENIED: Missing task or broker-issued scope.";
        if (task.SchemaVersion != "1.0")
            return "DENIED: Unsupported task schema.";
        if (string.IsNullOrWhiteSpace(task.TaskId) ||
            string.IsNullOrWhiteSpace(task.CorrelationId) ||
            !Guid.TryParse(task.CorrelationId, out _) ||
            !Guid.TryParse(task.TaskId, out _))
            return "DENIED: Task and correlation IDs must be valid UUIDs.";
        var s = task.Scope;
        if (!s.IsVerifiedByBroker)
            return "DENIED: Scope was not verified by the authorization broker.";
        if (!Guid.TryParse(s.TenantId, out _) || !Guid.TryParse(s.UserObjectId, out _) ||
            string.IsNullOrWhiteSpace(s.ProjectId) ||
            string.IsNullOrWhiteSpace(s.ConversationId) ||
            string.IsNullOrWhiteSpace(s.AuthorizationContextRef))
            return "DENIED: Incomplete bound tenant, principal, project or conversation identity.";
        if (s.DeadlineUtc <= DateTimeOffset.UtcNow)
            return "DENIED: Investigation deadline has expired.";
        if (s.DeadlineUtc > DateTimeOffset.UtcNow.AddMinutes(30))
            return "DENIED: Investigation deadline exceeds the 30-minute budget.";
        if (string.IsNullOrWhiteSpace(s.TargetResourceScope) ||
            !s.TargetResourceScope.StartsWith("/subscriptions/", StringComparison.OrdinalIgnoreCase) ||
            s.TargetResourceScope.Contains("..", StringComparison.Ordinal) ||
            s.TargetResourceScope.Contains('*') ||
            s.TargetResourceScope.Contains('?'))
            return "DENIED: Target scope must be an exact Azure subscription or child-resource ID.";
        if (task.RequestedOperation != "PlanReadOnlyAzureVmComplianceInvestigation")
            return "DENIED: Only read-only investigation planning is allowed.";
        if (s.AllowedToolNames is null ||
            s.AllowedToolNames.Any(name => name is not ("AzurePolicy.Read" or "Defender.Read")) ||
            s.AllowedToolNames.Count != s.AllowedToolNames.Distinct(StringComparer.Ordinal).Count())
            return "DENIED: Tool allowlist is invalid or includes unauthorized tools.";
        return null;
    }
}

Contract: Status Planned is neither Succeeded nor evidence of an Azure Policy/Defender result.

5. Implement the Supervisor delegation guard

This in-process coordinator validates the broker-issued task before calling an Investigation Agent and checks the returned correlation/task IDs, schema and claim evidence. Invalid outputs become explicit failures rather than untrusted findings.

C#Actual file: src/Jaws.Investigation/SupervisorInvestigationDelegator.cs
namespace Jaws.Investigation;

/// <summary>
/// Supervisor-side delegation coordinator. An in-process offline boundary only;
/// this does NOT provide remote Foundry A2A transport or grant MCP access.
/// </summary>
public sealed class SupervisorInvestigationDelegator(IInvestigationAgent investigation)
{
    public async Task<InvestigationResult> DelegateAsync(
        InvestigationTask task,
        CancellationToken cancellationToken = default)
    {
        ArgumentNullException.ThrowIfNull(task);
        // Validate the broker-issued task before calling a worker, fail closed.
        var rejection = InvestigationPlanner.Validate(task);
        if (rejection is not null)
        {
            return new InvestigationResult("1.0", task.TaskId, task.CorrelationId,
                "jaws-supervisor", "offline-step-c-0", InvestigationStatus.Denied,
                [], [], [], [], [rejection]);
        }

        var response = await investigation.InvestigateAsync(task, cancellationToken);
        if (response is null ||
            response.TaskId != task.TaskId ||
            response.CorrelationId != task.CorrelationId ||
            response.SchemaVersion != "1.0" ||
            string.IsNullOrWhiteSpace(response.AgentName) ||
            response.Status == InvestigationStatus.Succeeded &&
                response.Evidence.Count == 0)
        {
            return new InvestigationResult("1.0", task.TaskId, task.CorrelationId,
                "jaws-supervisor", "offline-step-c-0", InvestigationStatus.Failed,
                [], [], [], [], ["WORKER_RESULT_REJECTED: Task/correlation/schema identity or evidence integrity failed."]);
        }
        return response;
    }
}

6. Automated C# tests and expected behavior

The test harness is self-contained and requires no external test-framework packages or Azure account. Tests cover planned results, missing identity, forbidden operations, unauthorized tools, expired deadlines, correlation spoofing, cancellation and result integrity.

C#Actual file: tests/step-c/Program.cs
using Jaws.Investigation;

var failures = new List<string>();
int passed = 0;
async Task Check(string name, Func<Task<bool>> test)
{
    try
    {
        if (await test()) { passed++; Console.WriteLine($"PASS {name}"); }
        else { failures.Add(name); Console.Error.WriteLine($"FAIL {name}"); }
    }
    catch (Exception ex) { failures.Add(name); Console.Error.WriteLine($"FAIL {name}: {ex.Message}"); }
}
var guid = Guid.NewGuid().ToString();
var scope = new VerifiedInvestigationScope(
    TenantId: Guid.NewGuid().ToString(),
    UserObjectId: Guid.NewGuid().ToString(),
    ProjectId: "dev-project",
    ConversationId: "conversation-1",
    AuthorizationContextRef: "validated-broker-context",
    TargetResourceScope: "/subscriptions/00000000-0000-0000-0000-000000000001/resourceGroups/rg-test/providers/Microsoft.Compute/virtualMachines/vm-test-01",
    AllowedToolNames: ["AzurePolicy.Read", "Defender.Read"],
    DeadlineUtc: DateTimeOffset.UtcNow.AddMinutes(5),
    IsVerifiedByBroker: true);
var request = new InvestigationTask("1.0", guid, Guid.NewGuid().ToString(), "teams-message-1",
    "PlanReadOnlyAzureVmComplianceInvestigation", scope);
var planner = new InvestigationPlanner();
await Check("plan returns bound identity and no fabricated evidence", async () =>
{
    var result = await planner.InvestigateAsync(request);
    return result.Status == InvestigationStatus.Planned &&
        result.TaskId == request.TaskId && result.CorrelationId == request.CorrelationId &&
        result.Evidence.Count == 0 && result.VerifiedClaims.Count == 0 &&
        result.ProposedActions.Count == 0 && result.EvidenceRequirements.Count > 0;
});
await Check("reject unverified caller scope", async () =>
    (await planner.InvestigateAsync(request with { Scope = scope with { IsVerifiedByBroker = false } })).Status == InvestigationStatus.Denied);
await Check("reject forbidden operations", async () =>
    (await planner.InvestigateAsync(request with { RequestedOperation = "RemediateVm" })).Status == InvestigationStatus.Denied);
await Check("reject unauthorized tool", async () =>
    (await planner.InvestigateAsync(request with { Scope = scope with { AllowedToolNames = ["AzurePolicy.Write"] } })).Status == InvestigationStatus.Denied);
await Check("reject expired task", async () =>
    (await planner.InvestigateAsync(request with { Scope = scope with { DeadlineUtc = DateTimeOffset.UtcNow.AddSeconds(-1) } })).Status == InvestigationStatus.Denied);
await Check("reject unknown schema", async () =>
    (await planner.InvestigateAsync(request with { SchemaVersion = "2.0" })).Status == InvestigationStatus.Denied);
await Check("reject wildcard resource scope", async () =>
    (await planner.InvestigateAsync(request with { Scope = scope with { TargetResourceScope = "/subscriptions/*" } })).Status == InvestigationStatus.Denied);
await Check("reject incomplete tenant identity", async () =>
    (await planner.InvestigateAsync(request with { Scope = scope with { TenantId = "" } })).Status == InvestigationStatus.Denied);
await Check("reject invalid task correlation", async () =>
    (await planner.InvestigateAsync(request with { CorrelationId = "free-form" })).Status == InvestigationStatus.Denied);
await Check("reject overlong task budget", async () =>
    (await planner.InvestigateAsync(request with { Scope = scope with { DeadlineUtc = DateTimeOffset.UtcNow.AddHours(1) } })).Status == InvestigationStatus.Denied);
await Check("honor cancellation", async () =>
{
    using var cts = new CancellationTokenSource();
    cts.Cancel();
    try { await planner.InvestigateAsync(request, cts.Token); return false; }
    catch (OperationCanceledException) { return true; }
});
var delegation = new SupervisorInvestigationDelegator(planner);
await Check("Supervisor delegates a bound task and preserves correlation", async () =>
{
    var result = await delegation.DelegateAsync(request);
    return result.Status == InvestigationStatus.Planned &&
        result.TaskId == request.TaskId && result.CorrelationId == request.CorrelationId &&
        result.VerifiedClaims.Count == 0;
});
await Check("Supervisor blocks unverified tasks before specialist call", async () =>
{
    var result = await delegation.DelegateAsync(request with { Scope = scope with { IsVerifiedByBroker = false } });
    return result.Status == InvestigationStatus.Denied && result.AgentName == "jaws-supervisor";
});
await Check("Supervisor rejects a specialist that alters correlation", async () =>
{
    var fake = new StubInvestigationAgent(task =>
        new InvestigationResult("1.0",task.TaskId,Guid.NewGuid().ToString(),
            "jaws-investigation","offline",InvestigationStatus.Planned,[],[],[],[],[]));
    var result = await new SupervisorInvestigationDelegator(fake).DelegateAsync(request);
    return result.Status == InvestigationStatus.Failed && result.Diagnostics[0].StartsWith("WORKER_RESULT_REJECTED");
});
await Check("Supervisor rejects unsupported success without evidence", async () =>
{
    var fake = new StubInvestigationAgent(task =>
        new InvestigationResult("1.0",task.TaskId,task.CorrelationId,
            "jaws-investigation","offline",InvestigationStatus.Succeeded,[],[],["Claim without evidence"],[],[]));
    var result = await new SupervisorInvestigationDelegator(fake).DelegateAsync(request);
    return result.Status == InvestigationStatus.Failed;
});
Console.WriteLine($"Step C offline tests: {passed} passed; {failures.Count} failed.");
return failures.Count == 0 ? 0 : 1;

8. Security boundaries and exclusions

Not yet production security: a boolean broker-verification marker can be supplied by a caller and must not be treated as proof of real authorization. Production ingress must validate signed identity and project context; a server-owned authorization broker must bind user, tenant, resource and allowed tools before remote delegation. Worker endpoints need service authentication, signed or otherwise independently validated context, and strict provider scope enforcement.

The offline planner performs zero MCP calls, zero Azure reads/writes and no model inference. It rejects prohibited operations and intentionally makes no verified compliance claim. The human approval gate, live worker, MCP and Teams are future steps.
