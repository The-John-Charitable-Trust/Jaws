**Baseline:** 15 October 2026. **Authority:** Microsoft Learn / Microsoft technical documentation for product capabilities and best practices; checked-in code and acceptance receipts for actual JAWS implementation state.

This is the **installation and architecture track (Steps A onward)**, not the separate legacy [Agent Framework tutorial track](../agent-framework-track.md) (Steps 1–10). Future steps are **proposed placeholders** pending design approval. No future deployment is asserted.

## Step C final architecture and evidence

`jaws-supervisor-dev` v5 -> `jaws-investigation-a2a-dev` (`AgenticIdentityToken`, RemoteA2A) -> toolbox `jaws-investigation-a2a-tools` v2 -> `jaws-investigation-planner-dev` prompt agent v1. The standalone hosted `jaws-investigation-dev` v1 remains in place but **did not execute** the Step C A2A task. Hosted-agent A2A `SendMessage` returned `HOSTED_AGENT_NOT_SUPPORTED`; this is why the approved A2A callee is the prompt planner.

Acceptance, as reported in the Step C closure: Supervisor v5 immutable image `sha256:86c556fff7f54eb8ad81c84bc768093fd7bc083e941e9e16bbf1ea8bc0cfa289`; response `caresp_0ca3823766edf3dc00biTZLQVBWJSTvfc8sy4PrBBEV9zGJyvB`; A2A task `TASK_STATE_COMPLETED`. The operator command is `installer/Install-JawsThroughStepC.ps1 -Mode Validate` (read-only) or `-Mode Install -AcknowledgeStepCInstall` (one known repair per gate, then a re-check). Installer Pester 180 passed. [Closure commit](https://github.com/The-John-Charitable-Trust/Jaws/commit/401c7af751906a47c6d42cd0ffc1f473ad37f320); [merged PR #1](https://github.com/The-John-Charitable-Trust/Jaws/pull/1); runbook: [STEP-C-RUNBOOK.md](STEP-C-RUNBOOK.md).

**Do not** interpret Step C closure as proof of real Azure MCP investigation, remediation, or hosted Investigation execution. Those are explicitly scheduled after Step C.
