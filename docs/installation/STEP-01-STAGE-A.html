Step A — Azure discovery

Installer 0.4.10 · empty subscription · no resource creation

Quick Start Tutorial Standard guide Acceptance

Step A is read-only. Discover checks the signed-in identity, inventories that subscription, and writes a receipt. It does not create a resource group, a Foundry account, or a JAWS state file.

A1. Discover an empty subscription

git clone --branch main https://github.com/The-John-Charitable-Trust/Jaws.git
Set-Location .\Jaws
az login
az account set --subscription "<your-subscription-id>"
.\installer\Install-Jaws.ps1 -Mode Discover -NonInteractive -EnvironmentName your-environment -ResourceGroupName rg-jaws-your-environment -Location eastus
.\installer\Test-JawsStepA.ps1 -ReportPath .\installer\.local\jaws-step-a-discovery.your-environment.generated.json

Expected: STEP-A DISCOVERY PASS, Discovery: Greenfield, Subscription source: AzureCli, State file required: false, State file written: false, Azure writes: 0, and Prepared for Step B: true. An empty subscription prints Resource groups: 0 and Resources: 0. Test-JawsStepA.ps1 prints those lines and then Live Azure read: false.

Receipt: installer/.local/jaws-step-a-discovery.your-environment.generated.json. Nothing is written under installer/config/.

A2. Reconcile an existing installation

.\installer\Install-Jaws.ps1 -Mode Discover -EnvironmentName dev

The dev command reads installer/config/jaws-installation-state.dev.json. For any other installation, pass -StateFile with that installation's own file. A missing -StateFile stops at JAWS-STATE-003.

Failure recovery

  • JAWS-AUTH-001: sign in with az login and select the subscription. Nothing is created.
  • JAWS-AUTH-007: -SubscriptionId does not match az account show.
  • JAWS-STATE-003: the requested state file is missing. Discover does not invent one.
  • Prepared for Step B: false: the environment is dev, the resource group is rg-aiops-lab, or the group already exists in another region.

Acceptance

Offline Pester covers the empty-subscription path with a stand-in Azure CLI. A fresh-subscription receipt has not been archived, so greenfield Step A is not accepted. Dev-project reconciliation remains the previously accepted Step A evidence.

A-07, FedRAMP Moderate. Discovery creates no resource. Read the receipt against the inventory and record any Foundry account, Key Vault, registry, storage account, or container app that is publicly reachable before Step B. An empty subscription has nothing to record. Step A does not authorize the subscription. rg-aiops-lab-test2 has been deleted. Run Discover again before the next Step B plan.

Markdown copy · Step B

Uninstall to stop charges or start a new install

Discover creates no Azure resources and no charges. After Step B, or any later step, run this command to delete the whole environment, stop its Azure charges, and start a new complete install of the same names. It refuses dev. Uninstall details.

.\installer\Uninstall-Jaws.ps1 -EnvironmentName your-environment -AcknowledgeJawsUninstall
