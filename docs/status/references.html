Step-by-step acceptance register

Step A: Discovery and reconciliation accepted

Value proposition / achievement: An operator can inventory a chosen Azure subscription without a pre-existing JAWS installation, and can reconcile a named state file, without Azure writes.

Deliverable: Install-Jaws.ps1 -Mode Discover queries Azure Resource Graph. Rows stay unclaimed. -StateFile compares the named resources.

Microsoft technical source: Azure Resource Graph, Resource Graph with Azure CLI, and the Reader role (Microsoft.ResourceGraph/resources/read). These sources govern the query. They do not certify a live JAWS installation.

Implementation: installer/Install-Jaws.ps1 and installer/modules/StepADiscovery.psm1.

Tests: tests/installer/StepADiscovery.Tests.ps1.

Acceptance criteria:
  • Read-only discovery succeeds without a JAWS state file
  • Resource Graph rows for the selected subscription stay Unclaimed
  • When -StateFile is supplied, named resources are compared and identity drift stops the run
  • No cloud changes, and the state file is not created or rewritten

Verification state: Pester covers the criteria above. A live Resource Graph query in a new subscription was not run with this change, so that execution is BLOCKED, not passed.
