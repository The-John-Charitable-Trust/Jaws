Step A manual verification

Run discovery with installer/Install-Jaws.ps1 -Mode Discover, then validate the local report with installer/Test-JawsStepADiscovery.ps1. The validator does not call Azure. Use Reader on the subscription under test. Do not copy installer/config/jaws-installation-state.dev.json into another subscription.

Pester in A-014 has been run and does not call Azure. A-001, A-002, A-003, A-004, A-005, A-007, A-011, and A-012 need an authorized subscription and stay BLOCKED until that run is recorded. Do not mark them passed from the unit tests.
